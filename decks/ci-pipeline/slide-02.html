THE QUESTION

What CI answers on every commit

Can main be released with this commit in it?

CI is not a place to run tests. It is that one question, answered on every commit — and the answer is only worth having while a red build means exactly one thing.

Every stage that answers something else makes a red build mean a little less.

THREE WAYS IT GETS DILUTED

Work that answers a different question

Nightly soak runs, full browser matrices

Work nobody reads the answer to

Reports produced, archived, never opened

Work that answers nothing

A suite retried until it happens to pass
