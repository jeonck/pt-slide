WHEN IT IS ALREADY SLOW

When the pipeline is already slow

A slow pipeline is a scope problem before it is a speed problem.

01

Attribute the time

Per stage, not per pipeline. A total gives you nothing to act on.

02

Ask what the stage is for

Which question does its failure answer? If none, nothing else matters.

03

Move it or delete it

If a failure does not mean “do not merge”, it leaves the gate.

04

Then optimise the rest

Cache and shard what genuinely has to be there.

Optimising first only makes a stage that should not exist finish sooner.
