03 · THE TEST

The test an alert must pass to earn a page

Three questions. A no to any one of them means this is not a page.

01

URGENT

Does waiting until morning make it worse?

IF NO · SEND TO TICKET

02

ACTIONABLE

Is there a step someone can take right now?

IF NO · DELETE OR FIX

03

HUMAN ONLY

Can only a person take that step?

IF NO · AUTOMATE IT

All three, or it is not a page. Two out of three is still someone's night.
