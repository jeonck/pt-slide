DIAGNOSIS

The problem is usually not MLOps — it is repeatability

01

Training lives in notebooks

The run that produced the model in production cannot be reproduced.

02

Deployment is a person

One engineer ships every model, and the steps live in their head.

03

Retraining is a memory

Nobody can say when a model was last refreshed, or on what data.

04

Nobody owns the boundary

Data platform and ML team each assume the other handles features.

None of these is fixed by a tool. They are fixed by making one path the only path.
