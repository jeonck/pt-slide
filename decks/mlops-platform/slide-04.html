SEQUENCE

Three phases, each stopped by a criterion, not a date

PHASE 01

REPEATABLE

Every model is produced by a pipeline, not a laptop.

EXIT

Any model in production can be rebuilt from its commit.

PHASE 02

OBSERVABLE

Inputs, outputs and drift are visible without a request.

EXIT

On-call can answer “is this model healthy” without the ML team.

PHASE 03

SELF-SERVE

A new team ships a model without the platform team in the loop.

EXIT

A team onboards using the documentation alone.

Phases are gates, not calendar quarters — no dates appear here because none can be sourced.
