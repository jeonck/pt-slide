Three concessions the word actually asks for

Concession one

No names in the cause field

A name is not a mechanism. “Ran the wrong command” names where the system allowed it. The field takes conditions: what was reachable, what was open.

Concession two

An owner and a date

One person, not a team; a calendar date, not a quarter. When a team owns it, nobody is late, because nobody was ever due. Without both, it is a wish, not a plan.

Concession three

A repeat is a new incident

If the same failure returns and nobody reopened the record, it is not the old one again. It is evidence the first fix never landed: new review, new owner, new date.

Source — none. Every claim here is mechanical, not measured.
