## Checks
- [x] System consistency: PASS — One furniture system on all six sheets, cover included: an 11pt mono kicker row (section label left, `SHEET NN / 06` right), a one-line 23pt title, a 1px full-width rule, `main`, then a 10pt mono footer row carrying the deck slug and the source caption. Because the header block and the footer are siblings of `main` and every title is `white-space: nowrap` with measured clearance, the rule lands at an identical y on all six PNGs — verified on the contact sheet at `decks/slo/contact-sheets/sheet-01.png`, where the six rules and the six footer baselines line up across the grid. Two backgrounds (`#FFFFFF` canvas, `#F2F2F2` used once, for the ledger head row on 04), two typefaces (Geist for titles/body/card headers, Geist Mono for every label, caption and step number), and no accent because the style forbids one. Four layout patterns, each used deliberately: split cover (01), paired panels (02), horizontal process over paired columns (03), comparison ledger (04), card row (05), ruled decision rows (06). Every body sheet closes with the same statement band above a rule.
- [x] Color discipline: PASS — `grep -oh '#[0-9A-Fa-f]\{6\}'` over all six files returns exactly four values: `#000000` (50), `#666666` (22), `#F2F2F2` (2), `#FFFFFF` (9). All four are spec tokens verbatim. The palette was **not extended** — no harmonic colour was needed and none was invented, so there is nothing to record on that axis. The fifth token, `#999999` (text disabled), is deliberately unused: with only two text roles in this deck (prose and label) a third grey would have been a distinction without a job. The style's headline prohibition — "어떤 컬러도 쓰지 않는다" — holds literally: there is no chromatic value anywhere in the deck.
- [x] AI slop tropes: PASS — No gradient of any kind; `grep` for `gradient` returns zero across all six files, including the radial-gradient dot-grid trick. No shadow, no border-radius: `grep` returns zero for both, so `shape.radius: 0px` holds literally and every panel, node, card and cell is a hard rectangle. No rounded card with a left stripe used as a generic container. No SVG illustration — the only SVG in the deck is the three process connectors on slide 03, which is the spec's own `diagram.connector` vocabulary (1px line, 6px outline triangle arrowhead). No emoji, icon or clipart anywhere, per the Avoid list; the step markers on 03, the card indices on 05 and the row indices on 06 are the spec's mono `01`/`02` numerals. No 3×2 icon-and-blurb grid. The font stack is not generic: Geist and Geist Mono are the two faces the spec names, embedded locally from `@fontsource/geist-sans` and `@fontsource/geist-mono`, which the framework explicitly exempts from the generic-stack prohibition. `grep` for `http` returns zero across all six saved files.
- [x] Content discipline: PASS — **There is no number anywhere in this deck** other than sheet numbers and step ordinals. No chart, no canvas, no stat strip, no percentage, no duration, no count, no benchmark. The argument on every sheet is mechanical: 02 contrasts two ways of reading the same target; 03 names the four beats of the loop and what makes each half of it real; 04 is a ledger of four axes and what falls outside each; 05 names three ways the mechanism goes missing while the number stays; 06 turns those three into three decisions. `slide-outline.md` records under "no figures, and why" that availability targets, adoption effects and MTTR figures are unsourceable in this repo, and that inventing one would have been the weakest sentence on the sheet. Per the brief, the style's mandatory `slide.source_caption` slot carries that fact rather than a citation: every sheet's bottom-right caption reads `Source: none — no figures appear in this deck.` Nothing on screen is dressed to look like data.
