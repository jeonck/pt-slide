// 03 — ROLES

[ 03 / 06 ]

Three roles, defined by what they don't do

[ COMMANDER ]

// DOES

Declares, assigns each role by name, decides, and keeps the log.

// DOES NOT

Touch a terminal. A commander who debugs is no longer commanding.

[ COMMS ]

// DOES

Writes to stakeholders on cadence, including when nothing changed.

// DOES NOT

Diagnose, or promise a fix time. “We don't know yet” is a full update.

[ INVESTIGATOR ]

// DOES

One hypothesis at a time — tested, and the result said out loud.

// DOES NOT

Answer stakeholders, or change production without announcing it.
